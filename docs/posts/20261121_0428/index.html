자꾸 굴러다니는 작은 소품들 깔끔하게 정리할 수 없을까?

외출할 때 비상약이나 작은 귀걸이, 헤어핀 같은 소품들을 챙기다 보면 주머니나 가방 안에서 굴러다녀서 찾기 힘들었던 적 다들 있으시죠? 저도 평소에 아기자기한 소품이나 꼭 챙겨야 하는 약을 들고 다닐 일이 많은데, 파우치 안에 그냥 넣기에는 너무 작아서 마땅히 마음에 드는 전용 케이스가 없더라고요.


시중에서 파는 일반적인 플라스틱 약통이나 미니 상자들은 디자인이 조금 아쉽거나 크기가 어정쩡해서 가방에 들고 다니기가 은근히 꺼려졌습니다. 그래서 이번에는 내가 직접 마음에 드는 감성을 담아 3D 프린터로 근사한 미니 케이스를 뽑아보자는 생각이 들었어요.


가방 외부에 키링처럼 걸어둘 수 있는 고리가 있으면서도, 내부에는 칸막이가 정갈하게 나눠져 있어서 내용물이 서로 섞이지 않는 구조를 떠올려봤습니다. 거기에 짙은 밤하늘 느낌의 바탕에 샛노란 초승달과 하얀 별을 입체로 얹어주면 정말 귀여울 것 같아 바로 3D 모델링 작업을 시작했습니다.



밤하늘을 쏙 담아낸 달과 별 디자인의 첫인상

출력을 모두 마치고 완성된 케이스를 한 손에 쥐어보았을 때 가장 먼저 느껴진 건 아기자기한 형태감이었습니다. 시크한 검은색 바탕 위에 노란색 초승달과 흰색 별들이 조화롭게 올려져 있으니 보기만 해도 절로 미소가 지어지더라고요.


전체적인 외형은 손안에 쏙 들어오는 부드러운 원형 디자인으로 다듬었습니다. 크기가 너무 크면 가방 옆에 매달았을 때 거추장스럽고, 반대로 너무 작으면 안에 들어가는 소품이 거의 없어서 적절한 밸런스를 잡는 데 꽤 공을 들였습니다.


무게감 역시 3D 프린팅 특유의 내부 채움 덕분에 아주 가벼워서 가방 고리에 매달아도 전혀 부담스럽지 않은 수준입니다. 한눈에 들어오는 선명한 달 모티브 덕분에 밋밋한 가방에 감성적인 포인트를 더해주는 훌륭한 패션 아이템으로 변신했습니다.



4칸 분할구조와 힌지까지 직접 설계하며 신경 쓴 점

이번 모델링 작업에서 가장 공을 들인 핵심은 뚜껑의 열고 닫힘 동작과 견고한 힌지 구조를 구현하는 부분이었습니다. 열쇠고리나 가방 고리를 꽂을 수 있는 구멍을 측면에 자연스럽게 일체형으로 통합하여 별도의 연결부품 없이도 튼튼하게 유지되도록 제작했어요.


뚜껑 뒤쪽의 개폐 힌지축 역시 출력 직후에 뻑뻑하지 않고 부드럽게 돌아가도록 정밀하게 공간 유격을 조정했습니다. 뚜껑을 꽉 닫았을 때 감기는 걸쇠 부분도 적당한 장력을 가지도록 설계하여, 가방에 달고 움직여도 내부 소품이 쏟아질 염려가 없습니다.


측면에서 바라본 실물 표면에는 3D 프린터 특유의 촘촘하고 정교한 레이어 결이 느껴지는데, 이 미세한 결 덕분에 손으로 잡았을 때 쉽게 미끄러지지 않는 그립감도 생겼습니다. 여러 번의 유격 테스트를 거쳐 출력한 보람이 느껴지는 순간이었어요.



실물로 만나는 4칸 수납공간과 내부 완성도

뚜껑을 시원하게 180도로 펼치면 내부에 정갈한 십자 형태의 격자 칸막이가 한눈에 들어옵니다. 보관함을 공간별로 정확히 4등분 해두었기 때문에 작은 소품들을 목적에 맞게 나누어 담아두기 아주 좋습니다.


첫 번째 칸에는 작은 귀걸이나 피어싱을 넣고, 두 번째 칸에는 비상용 알약을 넣으며, 나머지 공간에는 클립이나 메모용 핀 같은 문구류를 분류해 넣으면 딱 맞습니다. 각 칸의 벽면 높이도 덮개와 밀착되도록 맞추어서 케이스가 뒤집혀도 안에서 내용물이 섞이지 않아요.


바닥면과 내부 격자의 마감 상태도 매끄럽게 잘 나와서 먼지가 쉽게 쌓이지 않고 소품을 꺼낼 때 걸림 없이 부드럽게 집을 수 있습니다. 직접 아이디어를 내고 조립 구조를 완성해서인지 이렇게 정갈하게 딱 맞아떨어지는 내부를 볼 때마다 뿌듯한 마음이 듭니다.
