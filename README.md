# 네이버 블로그 자동 글쓰기

## ★ 권장: 글쓰기 도우미 (`글쓰기도우미.bat`) - 네이버 로그인 없음, 계정 위험 없음
1. `글쓰기도우미.bat` 더블클릭 → AI 키(Gemini 무료) 넣고 [설정 저장]
2. 주제 입력 또는 [실시간 인기 주제] 클릭 → [② 글 만들기 (사진 포함)]
3. 30초~1분 뒤 미리보기 페이지가 열림 (AI 글 + 사진 + 사진 설명)
4. 평소 브라우저에서 네이버 블로그 [글쓰기] → ① 제목 복사·붙여넣기 → 본문 칸 클릭 → ② 본문 전체 복사·붙여넣기 → 발행 때 ③ 태그
5. 사진이 빠지면 [글 복사] / [사진N 복사]로 하나씩, 또는 [글 폴더 열기]에서 사진 파일을 끌어다 놓기
- 사진 순서: 내 사진 폴더 → Pixabay(무료 키, 선택, 사진 품질 더 좋음) → 위키미디어(출처가 사진 아래 자동 표기, 지우지 마세요)
- 자동 모드: 검색량 1000+ 이슈를 하루 1번 글로 미리 써 두고 알림. 네이버에는 접속하지 않음
- 만든 글은 `posts` 폴더에 날짜별로 저장

---

## (구) 에디터 자동 입력 버전 (`run.bat`) - 네이버 보안 확인이 늘어날 수 있어 비권장

주제 입력 → 무료 AI(Google Gemini)가 글 작성 → 네이버 스마트에디터에 자동 입력. 발행은 항상 직접.

## 실행
1. `run.bat` 더블클릭 (처음 한 번 패키지 설치)
2. **AI 키**와 **블로그 아이디**(blog.naver.com/아이디) 입력 → 설정 저장
   - 무료 키: https://aistudio.google.com/apikey 에서 Google 계정으로 로그인 → [API 키 만들기] → 복사해서 붙여넣기
   - 무료 등급은 하루 사용량 제한이 있고, 입력한 내용이 Google 서비스 개선에 쓰일 수 있습니다
   - Claude 키(sk-ant-...)를 넣으면 자동으로 Claude(유료)를 씁니다
3. **네이버 로그인 창 열기** → 열린 Edge 창에서 직접 로그인 (한 번만, `browser_profile` 폴더에 유지됨)
4. 글 종류(홈판용 / 검색용 / 브랜드) 선택, 주제 입력 또는 **실시간 인기 주제** 클릭
5. **② 글 만들기** → 오른쪽에서 제목/본문/태그 확인·수정
6. **③ 에디터에 채우기** → 에디터에서 내용 확인 → **[태그 복사]** 후 직접 **[발행]** (프로그램은 발행하지 않습니다)

## 파일
| 파일 | 역할 |
|---|---|
| app.py | 화면(GUI) |
| writer.py | AI 글 생성 (Gemini 무료: gemini-3.8-flash → 한도 초과 시 gemini-3.5-flash-lite / Claude 키면 claude-opus-5-5) |
| trends.py | Google 트렌드 한국 인기 키워드 |
| naver.py | Edge 자동 조작 (스마트에디터 입력/발행) |

## 사진
- [사진 추가]로 고른 사진: 첫 장은 맨 위(대표), 나머지는 소제목 앞에 들어갑니다.
- 자동 모드는 [사진 폴더]에서 파일 이름에 키워드가 들어간 사진을 먼저 고르고, 없으면 무작위로 고릅니다.
- 뉴스 사진 등 남의 사진은 저작권 문제가 생기니 직접 찍었거나 사용 허락된 사진만 넣으세요.

## 자동 모드
- Google 트렌드(한국)에서 검색량이 설정값(기본 1000+) 이상인 새 이슈를 10분마다 확인합니다.
- 찾으면 뉴스 제목을 근거로 AI가 글을 쓰고, 사진을 넣어 **임시저장만** 합니다. 발행은 하지 않습니다.
- **하루 1번만** 동작합니다. 프로그램을 켜 둔 동안만 동작합니다.

## 계정 보호 장치 (naver.py 의 LIMITS)
- 자동 발행 기능 없음 (발행은 항상 직접)
- 임시저장 하루 최대 3개
- 글 작업 사이 최소 30분 간격
- 로그인이 풀리면 자동으로 다시 로그인하지 않고 멈춥니다. 반복 로그인은 네이버 '보호조치'(휴대전화 인증)를 부릅니다.
- 입력은 사람 속도에 가깝게 나눠서 넣습니다.
- 그래도 자동화 도구 사용은 정지 위험이 0이 아닙니다.

## 주의
- 비밀번호는 프로그램이 입력하지 않습니다. 로그인은 항상 직접 하세요.
- `config.json`에 AI 키가 평문 저장됩니다. 공유하지 마세요.
- 네이버는 짧은 시간 대량 자동 발행을 스팸으로 판단해 저품질/제재할 수 있습니다. 하루 몇 개 이내, 직접 검토 후 발행을 권장합니다.
- 네이버가 에디터 화면을 바꾸면 `naver.py`의 선택자(`.se-documentTitle` 등)를 고쳐야 합니다.
